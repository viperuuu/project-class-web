STANDAR KUALITAS LAUTKECIL

Mengapa Berbelanja di LautKecil?

Setiap ikan dirawat dengan standar budidaya tinggi untuk memastikan tiba dengan sehat dan siap mewarnai akuariummu.

🌿

Karantina Ketat 14 Hari

Semua ikan melalui masa observasi dan karantina ketat untuk memastikan bebas jamur, kutu, dan parasit sebelum dikirim.

📦

Kemasan Standar Oksigen

Dikemas dengan kantong plastik ganda bertekanan oksigen murni dan dilapisi box styrofoam khusus tahan guncangan dan isolasi suhu.

🛡️

Garansi Hidup (D.O.A) 100%

Jika ikan mengalami kendala selama perjalanan, kami siap memberikan ikan pengganti atau pengembalian dana penuh tanpa syarat rumit.

💬

Bimbingan Aquarist Gratis

Bingung soal setup tank atau pakan? Tim ahli aquarist kami siap memandu Anda secara personal kapan pun dibutuhkan.

PANDUAN PEMULA & PENGHOBI

Aklimatisasi: Sambut Teman Kecilmu

Ikuti 4 langkah mudah ini agar ikan baru cepat beradaptasi dan tidak stres dengan air akuariummu.

LANGKAH 01

Penyetaraan Suhu

Apungkan kantong plastik berisi ikan di atas air akuarium selama 15–20 menit hingga suhu air kantong dan akuarium seimbang.

LANGKAH 02

Campur Air Bertahap

Buka kantong perlahan, lalu tambahkan 1–2 gelas air akuarium ke dalam kantong setiap 5 menit untuk menyamakan pH air.

LANGKAH 03

Lepas dengan Lembut

Gunakan serokan halus untuk memindahkan ikan ke akuarium. Hindari memasukkan air sisa bawaan kantong ke akuarium.

LANGKAH 04

Puasakan 24 Jam

Redupkan lampu akuarium beberapa jam dan jangan langsung memberi makan di hari pertama agar ikan tidak kembung karena stres.

ARSITEKTUR & DOKUMENTASI PROYEK

Spesifikasi REST API & Database SQLite

1. Dokumentasi RESTful API HTTP JSON API

Web ini terintegrasi penuh dengan backend REST API bawaan Node.js tanpa dependensi eksternal. Semua respons menggunakan format standar JSON.

Metode Endpoint URL Keterangan & Parameter
GET /api Ringkasan endpoint API dan metadata aplikasi toko.
GET /api/products Katalog ikan hias. Mendukung parameter query: ?category=, ?search=, dan ?sort=price-asc|price-desc.
GET /api/products/:id Detail satu produk berdasarkan ID unik (contoh: /api/products/betta-koi).
POST /api/orders Membuat transaksi pesanan baru. Menyimpan data pelanggan, detail produk, mengurangi stok ikan, dan menerapkan transaksi atomik SQLite (ACID).

PRAGMA foreign_keys = ON;

CREATE TABLE IF NOT EXISTS products (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  price INTEGER NOT NULL CHECK (price >= 0),
  stock INTEGER NOT NULL DEFAULT 0 CHECK (stock >= 0),
  badge TEXT NOT NULL,
  description TEXT NOT NULL,
  image TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS customers (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL CHECK (length(trim(name)) >= 2),
  email TEXT NOT NULL COLLATE NOCASE UNIQUE,
  address TEXT NOT NULL CHECK (length(trim(address)) >= 8)
);

CREATE TABLE IF NOT EXISTS orders (
  id TEXT PRIMARY KEY,
  customer_id INTEGER NOT NULL,
  status TEXT NOT NULL DEFAULT 'menunggu konfirmasi',
  total INTEGER NOT NULL DEFAULT 0 CHECK (total >= 0),
  created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (customer_id) REFERENCES customers(id) ON DELETE RESTRICT
);

CREATE TABLE IF NOT EXISTS order_items (
  order_id TEXT NOT NULL,
  product_id TEXT NOT NULL,
  product_name TEXT NOT NULL,
  quantity INTEGER NOT NULL CHECK (quantity > 0),
  unit_price INTEGER NOT NULL CHECK (unit_price >= 0),
  subtotal INTEGER NOT NULL CHECK (subtotal = unit_price * quantity),
  PRIMARY KEY (order_id, product_id),
  FOREIGN KEY (order_id) REFERENCES orders(id) ON DELETE CASCADE,
  FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE RESTRICT
);

CREATE INDEX IF NOT EXISTS idx_orders_customer_created
  ON orders (customer_id, created_at);

CREATE INDEX IF NOT EXISTS idx_order_items_product
  ON order_items (product_id);
